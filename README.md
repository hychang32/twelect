# 台灣選舉結果村里地圖

**線上版：https://hychang32.github.io/twelect/**

把中央選舉委員會的選舉資料抓下來，join 上內政部村里界圖，產生一張
**單一 HTML 檔、可離線開啟**的互動地圖：每個村里塗上該地最高票候選人
所屬政黨的代表色，得票率越高顏色越深，無黨籍一律灰色。

沒有任何第三方相依套件，只需要 Python 3.10 以上。

## 用法

```bash
# 1. 看有哪些選舉可以畫
python3 -m twelect list                    # 2010 年以後
python3 -m twelect list --year 2022
python3 -m twelect list --keyword 總統 --all

# 2. 產生地圖（會自動下載並快取資料）
python3 -m twelect build 2022-MAYOR --open
```

輸出在 `out/<鍵值>.html`，直接用瀏覽器開啟即可，不需要架站。

### 鍵值

`<西元年>-<選舉代碼>`，例如 `2024-P0`（第 16 任總統副總統）、
`2022-C1`（直轄市長）、`2022-D2`（鄉鎮市長）。同年同類型有多場時，
後面會加上 `b`、`c`（例如 `2022-C2b` 是嘉義市長重行選舉）。

另有合併鍵值 **`<年>-MAYOR`**：2022 年的縣市長其實分成
「直轄市長」「縣市長」兩場辦理，嘉義市又因候選人於投票前過世而延到
12/18 重行選舉，三場合起來才是完整的全國地圖，這個鍵值會自動把它們
併在一起（同一縣市以較晚的那場為準）。

### 常用參數

| 參數 | 說明 |
|---|---|
| `-o, --output` | 自訂輸出路徑 |
| `--title` | 自訂標題 |
| `--open` | 產生後直接開啟瀏覽器 |
| `--refresh` | 忽略快取重新下載 |
| `--site` | 輸出到 `docs/` 並更新 GitHub Pages 索引頁 |

### 發布到 GitHub Pages

`docs/` 是 Pages 的來源目錄，裡面放產生好的地圖與一頁索引。

```bash
python3 -m twelect build 2020-P0 --site   # 產生地圖到 docs/ 並更新索引
python3 -m twelect site                   # 只重新產生索引頁
git add docs && git commit -m "add 2020 presidential map" && git push
```

推上去後 GitHub Pages 會自動更新。地圖是自包含的單檔，Pages 只當靜態檔送出去；
每張約 4MB，經 gzip 後傳輸約 1.1MB。

## 地圖上可以做什麼

- **上色依據**：`領先政黨`（各村里最高票者的政黨色＋其得票率深淺）或
  `單一政黨得票率`（選定一個政黨，看它的分布）。
- **選區**：下拉選單可聚焦到單一選區（例如只看臺北市長、或只看某個立委選區），
  地圖會自動縮放到該選區，其餘區域轉為灰色，上方概況、圖例與表格也一併縮到
  該選區範圍。選區超過 24 個時（立委、議員）下拉選單會依縣市分組。
- **色階範圍**：預設 `各選區獨立`——每個選區用自己的得票率分布當尺規。地方
  選舉每個選區的候選人和競爭程度都不同，全國共用一把尺規會讓「臺北市長 55%」
  和「雲林縣長 55%」看起來一樣深卻其實不可比。要跨選區比較時切成 `跨選區一致`。
- **行政層級**：村里／鄉鎮市區／縣市三段即時切換，上層由村里資料加總而來。
- **檢視**：地圖或表格；表格可搜尋、可排序閱讀，也是色彩之外的無障礙替代。
- **地圖大小**：預設「配合螢幕」——地圖高度自動壓到目前視窗剩下的空間，
  整頁（含頁尾）不用捲動就看得完，13 吋筆電聚焦到臺北市也能一次看完整。
  想看細節時按地圖右上角的 ⤢ 切成「滿版」，改成跟著欄寬走、以長寬比決定高度；
  這個選擇會記在瀏覽器裡。
- 滾輪縮放、拖曳平移、點選鎖定；可以縮到比初始畫面更小（最小 0.3 倍），
  聚焦選區後想看周邊時很有用。游標移到任一區域會顯示全部候選人的票數與得票率。
- 深淺色主題（預設跟隨系統）。

離島的金門、連江、澎湖離本島太遠，直接照經緯度畫會有一半畫面是海，
所以獨立成左側小圖，框右上角標示相對主圖的放大倍率；其餘皆為真實
地理位置（Web Mercator 投影）。金門的烏坵鄉、連江的東引鄉距離各自
縣治超過 100 公里，也各自獨立一格。

## 資料來源

| 用途 | 來源 |
|---|---|
| 得票數（到村里、投開票所層級） | 中選會選舉資料庫 `db.cec.gov.tw` 的靜態 JSON |
| 政黨顏色 | 中選會 `party_colors.json`，主要政黨改用約定俗成的顏色（見 `twelect/palette.py`） |
| 村里界圖 | 內政部國土測繪中心村里界圖 2021.09 版，取自 [taiwan-atlas](https://www.npmjs.com/package/taiwan-atlas) TopoJSON |

下載的原始資料快取在 `cache/`，界圖放在 `data/`，都不進版控。

## 已知限制

- **界圖是 2021 年 9 月版**。2022 年選前後有些縣市調整里界（臺東市、桃園、
  新北等），代碼對不上時會改用「同一鄉鎮內的村里名稱」比對，仍對不上的
  會列在頁尾警告：有界線沒票的村里在地圖上畫成斜線，有票沒界線的村里
  票數仍計入鄉鎮市區與縣市合計，只是不會出現在地圖上。以 2022 縣市長
  為例，這兩類各約 13 個與 60 個（總數約 7,700）。
- **界圖是簡化過的**（taiwan-atlas 的 10t 版，平均一個村里只有十個左右的頂點），
  所以聚焦到立委選區這種小範圍時，村里邊界會看得出是折線。換用國土測繪的
  完整版可以解決，代價是檔案大一個數量級。
- **連江縣是數個村合併計票**（例如「復興村、福沃村」為同一個投開票區），
  所以票掛在「投開票單位」上、界線掛在村里上，合併的村里會同色，
  往上加總時不會被重複計算。
- **總統副總統選舉**中選會把正、副總統各記成一列且票數相同，抓取時只留正總統
  那列並把副手併進名字（例如「賴清德・蕭美琴」），否則每張票會被算兩次。
- 目前只處理得票率，沒有處理投票率／選舉人數（中選會的 `profiles` 端點）。
- 選區是用「共用候選人」的連通分量自動推導的——一位候選人只會登記在自己的
  選區，所以共用候選人的投開票單位必定同屬一個選區。縣市長、鄉鎮市長、區域
  立委、議員都不必個別寫規則。選區名稱則取自涵蓋的行政區與中選會的選區代碼
  （例如「臺北市第 1 選區」）。

## 專案結構

```
twelect/
  cec.py        中選會靜態 JSON 用戶端（含快取、並行下載）
  site.py       GitHub Pages 索引頁
  geo.py        TopoJSON 解碼、Web Mercator 投影、離島小圖版面、SVG 路徑
  palette.py    政黨代表色
  build.py      得票資料 × 村里界圖 → 前端資料包
  render.py     把資料包塞進樣板
  template.html 地圖頁面本體（CSS＋原生 JS，無外部相依）
  cli.py        命令列
```

色階在 `template.html` 的 `rampFor()`：把政黨色轉成 OKLCH，固定同一段
明度區間、只保留各黨自己的色相與彩度，所以「深淺」在不同政黨之間可以
互相比較，深色模式則另外換一組明度錨點。
